# IMPLEMENTAR v0.111.0

Acceso directo a la invitación de Discord. Sin migración, dependencias ni variables de entorno
nuevas.

## Cambio

- Escritorio: enlace a Discord en el pie de la barra lateral, a la izquierda del selector de idioma.
- Móvil: enlace en la parte superior de Ajustes.

El enlace abre la invitación en una pestaña nueva. No se modifican las integraciones de webhooks.

## Verificación

- `npm run verificar`
- `npm run build`

No hay pasos manuales de base de datos ni de despliegue incluidos.
